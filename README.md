# ApriReader для Android

Приватный ридер книг: Kotlin, Jetpack Compose, Material 3. Без рекламы, без
покупок, без аналитики. Библиотека, прогресс чтения и статистика живут только на
устройстве.

Это отдельный нативный проект, а не порт Windows-версии
([Aprilarius/ApriReader](https://github.com/Aprilarius/ApriReader), Tauri + Rust
+ TypeScript).

---

## Что умеет

**Библиотека**
- Импорт папок и отдельных файлов через системный выбор (Storage Access
  Framework), доступ сохраняется между запусками.
- Форматы: EPUB, FB2 (в том числе `.fb2.zip`), PDF, TXT, HTML/XHTML, CBZ, CBR.
- Полка: сетка, список и компактный вид; сортировка по названию, автору, дате
  добавления, прогрессу; группировка по автору, серии, формату и прогрессу;
  избранное, поиск, фильтры.
- Потеря доступа к папке не удаляет книги: они помечаются недоступными, прогресс
  и закладки сохраняются и подхватываются обратно при повторном подключении.

**Чтение**
- Нативный рендер текста с настраиваемой типографикой: гарнитура (Literata,
  Inter, Atkinson Hyperlegible, Lexend и системные), кегль, интерлиньяж, трекинг,
  отступ абзаца, поля, ширина колонки в знаках, выключка, красная строка,
  переносы. Настройки можно сохранять в пресеты.
- **Бионическое чтение**: выделение якорной части каждого слова с настраиваемой
  долей и приглушением хвоста.
- **RSVP**: пословный режим с фиксированной точкой оптимального распознавания
  (ORP), паузами на знаках препинания и регулировкой скорости 100–900 слов/мин.
- Постраничный режим с зумом для PDF и комиксов; для PDF при этом доступен
  текстовый слой — бионика и RSVP работают и там.
- **Чтение вслух** системным TTS: подсветка озвучиваемого абзаца, регулировка
  скорости, переход по абзацам, автоматический переход к следующей главе. Голос
  работает на устройстве — текст книги никуда не отправляется.
- Оглавление, поиск по тексту книги, закладки и выделения абзацев с экспортом в
  Markdown.
- Полноэкранный режим, перелистывание нажатием по краям и кнопками громкости,
  тонкая полоса прогресса при скрытом управлении.

**Оформление**
- **Material 3 на жидком стекле**: панели полупрозрачные и окрашены акцентом
  текущей книги, углы сглажены непрерывной кривизной (squircle), под карточкой
  «продолжить чтение» цветёт размытая обложка. Плотность стекла проверена
  тестом на контраст — прозрачность не стоит читаемости.
- **Dynamic Cover Theming**: при открытии книги акцент интерфейса берётся из
  палитры обложки (Palette API), приводится к валидной схеме Material 3 и
  проверяется на контраст. Полка вне контекста книги остаётся нейтральной.
- Свой акцент можно закрепить за конкретной книгой или задать глобально —
  автоматика его не перезаписывает.
- Светлая и тёмная темы, следование системной, глубокий чёрный для OLED, стили
  страницы (бумага, сепия, графит, чёрный), опционально цвета Material You.

**Статистика**
- Время чтения, стрики, активность за неделю, 16 достижений. Считается локально.

## Приватность

- Ни одного стороннего SDK: нет аналитики, краш-репортинга, рекламы и биллинга.
- В собранном APK объявлено пять системных разрешений (проверяется командой
  `aapt dump badging`, см. ниже): `INTERNET`; `FOREGROUND_SERVICE` и
  `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `POST_NOTIFICATIONS` — чтобы
  аудиокнига продолжала играть и управлялась из уведомления, пока экран
  выключен; `ACCESS_NETWORK_STATE` — не запрашивается кодом приложения,
  приходит из AndroidX Media3/ExoPlayer (доступа к личным данным не даёт).
  Рядом присутствует `com.aprireader.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION`
  — приложение объявляет его само, уровень защиты `signature`, наружу оно
  ничего не открывает.
- `INTERNET` нужен ровно для одного действия:
  подтяжки метаданных книги, которую пользователь запускает кнопкой в карточке
  книги, после диалога согласия, показывающего, что именно будет отправлено.
  До этого действия HTTP-клиент даже не создаётся.
- Во время сетевого запроса на экране виден явный индикатор.
- Никакой облачной синхронизации: это сознательное ограничение версии.

## Сборка

Нужны JDK 17 и Android SDK с платформой 36.

```bash
./gradlew :app:assembleDebug
```

Юнит-тесты — 41 тест: парсеры форматов и кодировок, пути внутри EPUB, порядок
страниц комиксов, бионика, RSVP, серии дней и достижения, контраст тем:

```bash
./gradlew test
```

Статический анализ (сборка падает на ошибках lint):

```bash
./gradlew :app:lintDebug
```

Релизная сборка (минификация R8 включена):

```bash
./gradlew :app:assembleRelease
```

Для подписи положите в корень проекта `keystore.properties`:

```
storeFile=/абсолютный/путь/apri-release.jks
storePassword=...
keyAlias=apri
keyPassword=...
```

Файл не хранится в репозитории. Без него релиз собирается неподписанным.

Ключ для локальной установки можно сделать так (это **не** ключ публикации —
для Google Play нужен отдельный upload key, который вы храните сами):

```bash
keytool -genkeypair -v -keystore apri-dev.jks -alias apri-dev -keyalg RSA -keysize 4096 -validity 10000
```

Проверка того, что в собранном APK нет лишних разрешений:

```bash
aapt dump badging app/build/outputs/apk/release/app-release.apk | grep uses-permission
```

## Выпуск в Google Play

Play принимает только Android App Bundle:

```bash
./gradlew clean :app:bundleRelease
```

Готовый файл: `app/build/outputs/bundle/release/app-release.aab`.

Материалы карточки, ответы на форму Data Safety, политика конфиденциальности и
пошаговый чек-лист лежат в [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md),
[play/](play/) и [PRIVACY.md](PRIVACY.md). Графика для карточки генерируется
воспроизводимо:

```bash
javac -encoding UTF-8 -d build-tools-out tools/PlayAssets.java && java -cp build-tools-out PlayAssets play-assets
```

## Структура

```
bookformat/   Android-библиотека без UI: детекция форматов, ZIP-читатель с
              произвольным доступом, парсеры EPUB / FB2 / TXT / HTML / CBZ / CBR,
              текстовый слой PDF. Покрыта юнит-тестами.
app/
  data/       Room (библиотека, закладки, сессии, пресеты, достижения),
              DataStore (настройки), SAF-доступ, обложки, сеть метаданных.
  domain/     Модель книги и достижений.
  ui/         Compose по фичам: onboarding, library, reader, details, settings,
              stats, общая тема и компоненты.
  widget/     Виджет «текущая книга» на Glance.
```

Ключевые решения и их обоснование — в [DECISIONS.md](DECISIONS.md).
