# Форма Data Safety в Google Play — готовые ответы

Заполняется в Play Console → «Безопасность данных». Ответы соответствуют коду:
каждый пункт можно проверить по исходникам и по собранному APK.

---

## Раздел 1. Сбор и передача данных

| Вопрос Play | Ответ | Обоснование |
|---|---|---|
| Приложение собирает или передаёт какие-либо типы данных пользователя? | **Нет** | В приложении нет аналитики, рекламы, краш-репортинга и учётных записей. Единственный сетевой запрос отправляет название и автора книги, выбранной пользователем, и не содержит персональных данных или идентификаторов. |
| Данные шифруются при передаче? | **Да** (вопрос появляется только при ответе «да» выше) | Запросы идут по HTTPS, в манифесте `usesCleartextTraffic="false"`. |
| Пользователь может запросить удаление данных? | **Данные не собираются** | Все данные хранятся локально и удаляются вместе с приложением. |

> Если модерация попросит уточнить сетевой запрос: он выполняется только по
> явному нажатию пользователя в карточке книги, после диалога подтверждения,
> и адресован публичному API Open Library.

## Раздел 2. Практики безопасности

| Вопрос | Ответ |
|---|---|
| Данные шифруются при передаче | Да |
| Есть механизм запроса удаления данных | Не применимо: данные не покидают устройство |
| Приложение прошло независимую проверку безопасности | Нет |

## Раздел 3. Разрешения

| Разрешение | Зачем |
|---|---|
| `android.permission.INTERNET` | Подтяжка обложки и описания книги из Open Library по явному действию пользователя |
| `android.permission.FOREGROUND_SERVICE` | Воспроизведение аудиокниги продолжается при выключенном экране или свёрнутом приложении |
| `android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK` | Тип foreground-сервиса для воспроизведения медиа (обязателен на Android 14+ вместе с предыдущим) |
| `android.permission.POST_NOTIFICATIONS` | Уведомление с управлением плеером аудиокниги (пауза, перемотка) |
| `android.permission.ACCESS_NETWORK_STATE` | Не запрашивается кодом приложения напрямую — объявлено библиотекой AndroidX Media3/ExoPlayer (воспроизведение аудио); доступа к личным данным не даёт |

Разрешений на доступ к хранилищу приложение **не запрашивает**: файлы
открываются через системный выбор папки (Storage Access Framework), доступ
выдаёт сам пользователь и может отозвать его в настройках Android.

## Проверка перед отправкой формы

```bash
aapt dump badging app/build/outputs/apk/release/app-release.apk | grep uses-permission
```

Ожидаемый вывод — ровно шесть строк (пять из таблицы выше плюс подписное
разрешение приложения для собственного широковещательного приёмника):

```
uses-permission: name='android.permission.INTERNET'
uses-permission: name='android.permission.FOREGROUND_SERVICE'
uses-permission: name='android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK'
uses-permission: name='android.permission.POST_NOTIFICATIONS'
uses-permission: name='android.permission.ACCESS_NETWORK_STATE'
uses-permission: name='com.aprireader.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION'
```

Последняя строка — разрешение, которое приложение объявляет само для своего
же широковещательного приёмника (уровень защиты `signature`); в форме Data
Safety оно не упоминается. Если этот список когда-нибудь пополнится
разрешением, не объяснённым ни строкой кода, ни известной зависимостью —
это повод остановить публикацию и разобраться, а не обновить таблицу.

## Анкета возрастного рейтинга (IARC)

| Вопрос | Ответ |
|---|---|
| Насилие, кровь, оружие | Нет |
| Сексуальный контент, нагота | Нет |
| Ненормативная лексика | Нет |
| Наркотики, алкоголь, табак | Нет |
| Азартные игры, симуляция азартных игр | Нет |
| Взаимодействие пользователей, обмен сообщениями | Нет |
| Обмен местоположением | Нет |
| Покупки внутри приложения | Нет |
| Реклама | Нет |
| Пользовательский контент, доступный другим | Нет |

Отдельно стоит отметить в свободном поле: приложение открывает файлы, которые
пользователь выбирает на своём устройстве; их содержимое приложением не
модерируется и другим пользователям не передаётся.

Ожидаемый результат: рейтинг **3+ / Для всех**.
